## 🚀 Featured Projects

### 💳 Credit Card Fraud Detection

**End-to-end FinTech machine learning project**

Analyzed 10,000 synthetic credit-card transactions and developed a baseline fraud detection model.

**Highlights**
- Performed exploratory data analysis
- Investigated fraud patterns across transaction behavior
- Handled class imbalance
- Built a Logistic Regression classification model
- Achieved **0.9944 ROC-AUC**
- Achieved **73.33% fraud recall at a 0.30 decision threshold**
- Persisted the trained model using Joblib

🔗 [View Project](https://github.com/SiddeswarReddyAIML/AI-ML-Portfolio/tree/main/projects/01-python-data-analysis)

### 🛒 Online Retail Data Cleaning & EDA

**Large-scale retail data analysis project**

Performed data quality assessment and exploratory analysis on **541K+ online retail transaction records**.

**Highlights**
- Identified and handled exact duplicate records
- Investigated missing customer identifiers
- Analyzed returns and cancellations
- Investigated pricing and quantity anomalies
- Analyzed monthly sales trends
- Performed geographic sales analysis
- Analyzed product performance
- Segmented customers by purchase frequency
- Identified strong customer-value concentration

**Key finding**

The top **10% of identifiable customers generated approximately 60% of identifiable-customer transaction value**.

🔗 [View Project](https://github.com/SiddeswarReddyAIML/AI-ML-Portfolio/tree/main/projects/02-data-cleaning-eda)
