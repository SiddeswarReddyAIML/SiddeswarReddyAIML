## 🚀 Featured Projects

### 💳 Project 01 — Credit Card Transaction Analysis & Fraud Detection

**FinTech / Machine Learning**

End-to-end fraud detection project using **10,000 synthetic credit card transactions**.

**Highlights:**

- Exploratory data analysis and data-quality validation
- Feature engineering and one-hot encoding
- Logistic Regression fraud detection model
- ROC-AUC: **0.9944**
- Accuracy: **99.30%**
- Fraud Recall: **73.33% at 0.30 threshold**
- Business-oriented fraud threshold selection
- Model serialization with Joblib
- FastAPI prediction API
- Automated API testing with Pytest
- Dockerized deployment with health checks

🔗 [View Project on GitHub](https://github.com/SiddeswarReddyAIML/AI-ML-Portfolio/tree/main/projects/01-python-data-analysis)

### 📊 Project 02 — Online Retail Data Cleaning & Exploratory Data Analysis

**Data Analysis / EDA**

End-to-end data cleaning and exploratory analysis of **541,909 UCI Online Retail transactions**.

**Highlights:**

- Missing-value analysis
